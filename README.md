# 光鸭网盘清理与解散工具

基于 Vue 3、TypeScript 和 `vite-plugin-monkey` 的光鸭网盘 userscript，当前实现：

- **清理文件**：按后缀、文件类型、文件名关键词、目录名关键词、最大大小、包含/完整匹配、大小写和正则进行预扫描；由用户最终勾选后分批移入回收站。
- **解散子目录**：递归扫描选中目录；重名处理可选择“保留不处理（安全，默认）”、“按光鸭网盘默认操作”（通常自动追加 `(1)`、`(2)` 等）或“回收候选重名文件”；重新扫描确认无文件后，才把对应空目录移入回收站。
- **批量重命名**：对当前选中的文件和目录执行普通/正则替换、前后缀、递增序号及逐项编辑；默认保留文件扩展名，支持跳过冲突或自动追加 `(1)`、`(2)`，并可安全处理名称互换。

不实现 SHA1 清理，不调用清空回收站或永久删除。

## 安装

```bash
npm install
npm run build
```

然后在 Tampermonkey 或 Violentmonkey 中安装：

```text
dist/guangya-tools.user.js
```

打开 `https://www.guangyapan.com/#/home/all` 并登录。脚本会在光鸭原生工具栏旁显示“清理文件”、“解散子目录”和“批量重命名”。

## 安全行为

- 在 `document-start` 捕获页面发往 `api.guangyapan.com` 的最新鉴权上下文；不会把 token 输出到日志或 UI。
- 所有移动和删除固定最多 50 项一批，并等待服务端任务进入成功/失败终态；解散子目录移动时会先按来源父目录分组，避免光鸭接口返回“父目录不一致”。
- 清理/解散的预扫描会显示进度条、百分比、当前页/目录和累计项目数；递归扫描时已发现目录总数会动态增长。
- 点击“开始解散”后也会显示整体执行进度，状态文字包含当前选中目录、当前阶段和正在移动的来源子文件夹。
- 清理前显示结果表，只有用户最终勾选的项目会被处理。
- 批量重命名只处理当前选中项；执行前实时预览并复刻光鸭原生名称校验（255 字符、非法字符、保留名、点号边界等）。
- 重命名冲突可选择跳过，或在扩展名前自动追加 `(1)`、`(2)`；名称互换/循环使用临时名称中转，循环失败时会逆序尝试回滚并显示残留风险。
- 重名策略默认是安全跳过：目标目录已有同名文件/目录时跳过；候选文件之间重名时移动第 1 个、跳过后续同名项。也可选择交给光鸭默认处理，由服务端通常追加 `(1)`、`(2)` 等；最终行为以光鸭服务端为准。
- 第三种“回收候选重名文件”只回收子目录里的候选重名文件，不处理目标目录中原有同名文件；候选文件原来的直接父目录仅在复扫确认没有其他文件后才回收。
- 存在未移动文件、删除失败或扫描失败时，对应非空/不确定目录会保留。
- 取消只阻止后续批次；已经提交的服务端任务仍会等待终态。
- SPA 目录变化会关闭面板并取消后续操作。
- 解散结果会按目录展开显示冲突文件、保留目录和失败批次错误；可点击“复制失败/保留详情”生成诊断文本。

## 验证

```bash
npm test       # 核心规则和批处理测试
npm run build  # 类型检查并生成 userscript
```

真实接口已在隔离的临时目录中验证：分页列表、跨域鉴权复用、移动任务、任务轮询、普通删除进入回收站。测试临时目录只进入回收站，没有永久删除。
